# PGR_Make 0.8.1: пакетная установка инструментов

## Что изменилось

В окне **Pack Manager** добавлена кнопка **«Скачать необходимые инструменты»**.
Она открывает подтверждение со списком устанавливаемых пакетов и затем запускает фоновую CLI-команду:

```cmd
C:\PGR\PGR_Make.exe --home C:\PGR --pack-install-all
```

Задание устанавливает актуальные **проверенные версии из каталога** для четырёх категорий: GCC, Clang, CMake, Ninja. Проверенные версии выбираются по компонентам цифровых номеров версий; каталожные версии, уже успешно зарегистрированные в Pack, не скачиваются повторно. Программа **не утверждает**, что обнаруживает самый новый релиз в интернете в момент нажатия: каталог фиксируется и обновляется вместе с PGR_Make или дополняется через `Pack/catalog.json`.

## Встроенный каталог Windows x64 на 27 октября 2026 года

| Пакет | Содержимое | ZIP | SHA-256 |
|---|---|---|---|
| WinLibs UCRT, GCC 16.2.0 + LLVM/Clang 23.1.3 | Компиляторы и зависимости MinGW-w64 | около 424 МБ | `1f04e482797dc5f71fe2875cf2b743bfb9f5fd1de0955fdd3118438c0432ba5f` |
| CMake 4.4.4 | `cmake.exe`, средства CMake | около 54 МБ | `bace36e94b31c68ab6fa295f26dfa11219e0701cf7c94b0284a7d1cb13dac536` |
| Ninja 1.13.2 | `ninja.exe` | небольшой ZIP | `07fc8261b42b20e71d1720b39068c2e14ffcee6396b76fb7a795fb460b78dc65` |

Источники: официальный релиз WinLibs на GitHub и digest загруженного актива GitHub, релизы Kitware CMake, релизы Ninja с проверенной контрольной суммой. GCC и Clang устанавливаются **одним ZIP** и регистрируются под собственными идентификаторами `gcc@16.2.0@windows-x86_64` и `clang@23.1.3@windows-x86_64`. Скачивание происходит по HTTPS, архив сверяется с закреплённым SHA-256. Содержимое проверяется на опасные пути, символические ссылки и ограничения размера, затем исполняемые файлы запускаются с `--version`, после чего каталог перемещается в Pack и записывается реестр. ZIP WinLibs большой: предварительно обеспечьте несколько гигабайт свободного места.

### Где находятся инструменты

```text
C:\PGR\
  tools\catalog.json                (встроенные поддерживаемые версии)
  Pack\catalog.json                 (необязательные пользовательские версии / переопределения)
  Pack\registry.json
  Pack\gcc\16.2.0-windows-x86_64\mingw64\bin\g++.exe
  Pack\gcc\16.2.0-windows-x86_64\mingw64\bin\clang++.exe
  Pack\cmake\4.4.4-windows-x86_64\bin\cmake.exe
  Pack\ninja\1.13.2-windows-x86_64\ninja.exe
  Pack\Temp\
  Pack\Retired\
```

Пользовательские проекты и существующие версии остаются без изменений. Папка Pack используется **не вместо**, а вместе с обычным проектным выбором версий: после установки закрепите нужные инструменты в конфигурации проекта. MSVC, ARM/RISC-V toolchain, SDK плат и GTK4-runtime приложения не входят в универсальный набор: для них требуется отдельный, совместимый пакет.

## Безопасность и ошибки

- Без полного набора доверенных пакетов для текущей платформы массовая установка не начинается: ошибка прямо называет отсутствующие категории.
- Если зарегистрированная версия повреждена, процесс останавливается до скачивания.
- Загрузка, проверка SHA-256, распаковка и проверка версий выполняются отдельно для каждого ZIP. Ошибка останавливает процесс, уже установленные и проверенные инструменты сохраняются.
- При прерывании активной загрузки неполные данные остаются только во временной директории и удаляются откатом установки. Если остался аварийный `*.installing`, менеджер не перезаписывает его автоматически.
- GCC и Clang хранятся в общем каталоге. При удалении одного из них в карантин перемещается весь комплект; привязка **любого** из компиляторов к проекту блокирует такое удаление.
- PGR_Make ничего не записывает в системный PATH и не требует администраторских прав, если `C:\PGR` доступен для записи.

## Проверка

```cmd
C:\PGR\PGR_Make.exe --home C:\PGR --pack-list
C:\PGR\PGR_Make.exe --home C:\PGR --pack-catalog
```

Для Linux доступны дополнительные офлайн-тесты целостности общих ZIP-комплектов. Полная Windows-проверка скачивания и распаковки большого WinLibs ZIP должна выполняться на машине Windows: локальная сборка GTK4 в данной среде недоступна.
