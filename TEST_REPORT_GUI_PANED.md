# Отчёт о проверке GUI GtkPaned

Дата: 2026-10-26.

## Выполнено

- Сборка ядра CLI из исходников через CMake/Ninja/GCC: **успешно**.
- Базовый регрессионный пакет `tests/run_tests.py`: **успешно**.
- Feature-тесты `tests/run_features.py`: **успешно**.
- Тест CLI-моста GUI `tests/run_gui_bridge.py`: **успешно**.
- Новые CLI-команды и безопасный экспорт `tests/run_gui_commands.py`: **успешно**.
- Проверка структуры GUI `tests/test_gui_surface.py`: **успешно**.
- CTest (`diagnostics_parsing`): **успешно**.
- Синтаксический анализ GUI через GCC с **тестовыми объявлениями** GTK API: **успешно**. Это не является реальной сборкой/линковкой GTK4.

## Не проверено

- Нативная сборка и запуск GTK4 GUI на Windows с установленным GTK4 SDK.
- Интеграция с реальным MSVC, встраиваемыми toolchain и их пакетами GTK4.
- Полнота DLL-поставки GTK4 в `Pack/GTK4` на чистой Windows.

Перед выпуском бинарного дистрибутива следует выполнить сборку `PGR_REQUIRE_GUI=ON` под MSYS2 UCRT64 и интерактивный тест на машине Windows.
